Guide

From a plugged-in pad to a game that just works. Four steps, no settings to guess.

1

Make a profile

On the dashboard press New profile and pick the game's .exe. Every game gets its own profile, so nothing is shared by accident.

2

Say which pad plays

In the slot map the first row is the slot the game reads as controller 1. Pick your pad there, then the next one on the row below.

3

Check the buttons

Open Mapping and press a button on the pad — the diagram lights up. If a button is in the wrong place, click Learn on its row and press the real button once.

4

Copy into the game and launch

Press Copy to game: the right DLLs for the game's bit-ness and your mapping go into its folder. Launch from here or from your own shortcut — the profile travels with the files.

Extra controllers

Windows only has four controller slots. If you need more, open Virtual driver, add a controller per pad and press Start — Mapivo turns them into extra controllers Windows can see.
