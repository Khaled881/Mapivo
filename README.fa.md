# مپایو (Mapivo)

[English](README.md) | [فارسی](README.fa.md)

> دسته‌ات. هر بازی. به روش خودت.

مپایو یک برنامهٔ ویندوزی برای شناساندن دسته به بازی‌هاست. هر دسته‌ای (اکس‌باکس،
پلی‌استیشن، سوییچ، دسته‌های جنریک، فرمان) را وصل کن و مپایو کاری می‌کند که در
بازی‌ای که می‌خواهی بازی کنی مثل یک دستهٔ Xbox 360 کار کند — با پروفایل جدا برای
هر بازی، نقشهٔ دکمه‌ها، دِدزون و ویبره.

---

## نصب

فایل **`Mapivo-Setup-1.0.1.exe`** را از بخش [Releases](../../releases) دانلود و اجرا کنید.

- یک ستاپ برای هر دو ویندوز **x64** و **ARM64**؛ خودش نسخهٔ درست را انتخاب می‌کند.
- **نیازی به دسترسی ادمین نیست**: به‌صورت per-user در `%LOCALAPPDATA%\Programs\Mapivo` نصب می‌شود.
- اینستالر اول زبان را می‌پرسد (English / فارسی)، بعد Next و Next.
- مسیر نصب را خودتان انتخاب می‌کنید.
- شورتکات دسکتاپ (اختیاری) و شورتکات منوی استارت ساخته می‌شود.
- اگر **WebView2 Runtime** نصب نباشد خودکار دانلود و نصب می‌شود.
- برنامه self-contained است: **نیازی به نصب جداگانهٔ .NET 8 نیست**.
- حذف‌کننده در ویندوز (Apps & Features) ثبت می‌شود.

## قابلیت‌ها

| قابلیت | توضیح |
|---|---|
| دسته‌های اکس‌باکس | پشتیبانی کامل با XInput |
| دسته‌های پلی‌استیشن | DualSense، DualSense Edge، DualShock 4، DualShock 3 — پشتیبانی بومی HID همراه ماشهٔ تطبیقی و نور |
| دسته‌های نینتندو سوییچ | Switch Pro و Joy-Con با DirectInput |
| دسته‌های قدیمی / جنریک | هر دستهٔ جنریک DirectInput، استیک آرکید، فرمان و استیک پرواز |
| بازی‌های ۳۲ و ۶۴ بیتی | هر دو معماری، XInput و DirectInput |
| پروفایل جدا برای هر بازی | هر بازی نقشه، دِدزون و ویبرهٔ خودش را دارد |
| نقشه‌کردن دکمه‌ها | هر دکمهٔ فیزیکی را به هر دکمهٔ مجازی نگاشت کن، با پیش‌نمایش زنده |
| تنظیم دِدزون | دِدزون جدا برای استیک چپ/راست و ماشه‌ها |
| تست ویبره | کم / متوسط / زیاد و لرزش بی‌پایان برای هر اسلات |
| ویبره برای دسته‌های قدیمی / جنریک | با force feedback DirectInput و گزارش‌های خام HID کار می‌کند، نه فقط XInput |
| کپی به بازی (DLL پروکسی) | DLLهای `xinput*.dll` و `dinput8.dll` را داخل پوشهٔ بازی می‌گذارد — بدون نیاز به درایور |
| حالت درایور مجازی | دستهٔ مجازی سراسری با ViGEmBus، بدون DLL داخل پوشهٔ بازی |
| قطع/وصل آنی | وصل یا قطع شدن دسته همان لحظه با اعلان‌های دستگاه ویندوز تشخیص داده می‌شود، بدون پولینگ یا رفرش |
| بررسی آنتی‌چیت | قبل از کپی، پوشهٔ بازی برای EAC، BattlEye، Vanguard، Ricochet، FACEIT، ESEA، GameGuard، XignCode و APIهای آنلاین اسکن می‌شود و در صورت پیدا شدن پاپ‌آپ هشدار می‌آید |
| خوش‌آمد اولین اجرا | انتخاب English/فارسی و بعد دکمهٔ «شروع»؛ پیش‌فرض انگلیسی |
| دو زبان | رابط کامل انگلیسی و فارسی (راست‌به‌چپ) |
| اینستالر | اول انتخاب زبان، مسیر دلخواه، شورتکات دسکتاپ و استارت‌منو، آیکون، حذف‌کننده |
| نصب خودکار WebView2 | اگر نباشد خودکار دانلود و نصب می‌شود |
| Self-contained | .NET 8 داخل برنامه است — نصب جدا لازم نیست |
| گزارش‌ها و راهنما | صفحهٔ گزارش‌ها و راهنمای گام‌به‌گام داخل برنامه |

## پیش‌نیازها

| پیش‌نیاز | برای چه |
|---|---|
| ویندوز ۱۰/۱۱ (x64 یا ARM64) | همه چیز |
| [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) | رابط کاربری (اگر نباشد اینستالر خودکار نصبش می‌کند) |

## ساخت

```bash
dotnet publish src/Mapivo.App/Mapivo.App.csproj -c Release -r win-x64   --self-contained true -o out/publish/x64
dotnet publish src/Mapivo.App/Mapivo.App.csproj -c Release -r win-arm64 --self-contained true -o out/publish/arm64
```

DLLهای هوک جدا با Zig ساخته می‌شوند:

```bash
tools/build-hook.bat
```

خط `ZIG=` بالای `tools/build-hook.bat` را به مسیر `zig.exe` خودت تغییر بده.
خروجی در `out/DLL/x86` و `out/DLL/x64` قرار می‌گیرد.

بعد اینستالر را با [Inno Setup](https://jrsoftware.org/isinfo.php) 7 بساز:

```bash
"C:\Program Files\Inno Setup 7\ISCC.exe" installer\Mapivo.iss
```

فایل ستاپ در `out/installer/Mapivo-Setup-1.0.1.exe` ساخته می‌شود و شامل هر دو نسخهٔ x64 و ARM64 است.

## بازی آنلاین و آنتی‌چیت

این مهم‌ترین بخشی است که قبل از استفادهٔ آنلاین باید بخوانی.

**بازی آفلاین و تک‌نفره: هیچ ریسکی ندارد.**

روش **کپی به بازی** در مپایو، DLLهای `xinput*.dll` و `dinput8.dll` را داخل
پوشهٔ بازی می‌گذارد. آنتی‌چیت‌های کرنلی (Vanguard، Easy Anti-Cheat، BattlEye،
Ricochet) پوشهٔ بازی را برای DLLهای غریبه اسکن می‌کنند و ممکن است:

- اجازهٔ اجرای بازی را ندهند (`Untrusted system file`) که حالت رایج است؛ یا
- در موارد نادر حساب را علامت بزنند یا سایه‌بن کنند.

مپایو پوشهٔ بازی را برای نشانه‌های آنتی‌چیت اسکن می‌کند و اگر پیدا کند، قبل از
کپی یک پاپ‌آپ تأیید نشان می‌دهد.

**هرگز در بازی‌های آنلاین رقابتی از کپی به بازی استفاده نکن.** به‌جایش از
**درایور مجازی** (ViGEmBus) یا Steam Input / DS4Windows استفاده کن. آن‌ها یک
دستهٔ مجازی در سطح سیستم اضافه می‌کنند و هیچ DLL داخل پوشهٔ بازی نمی‌گذارند، پس
آنتی‌چیت سخت‌افزار عادی دسته را می‌بیند.

خود استیم (VAC) برای نقشه‌کردن دسته بن نمی‌دهد، چون تبدیل دسته به XInput هیچ
برتری ناعادلانه‌ای نمی‌دهد. ریسک فقط از آنتی‌چیت خود بازی می‌آید.

